How to Play Agnes

The Goal: Agnes is a beautiful "open-information" variant of Klondike where all 28 tableau cards are dealt face up. Move all cards to the 4 Foundation piles to win!

The Base Rank

  • The very first card dealt establishes the Base Rank for the foundations.
  • For example, if an 8 is dealt, all foundations must start with an 8 and build UP in the same suit, wrapping from King back to Ace.

Tableau & Reserve Rules

  • Build the Tableau columns DOWN. (Alternating colors for Agnes Bernauer, or Same color for Agnes Sorel).
  • Empty spaces are strictly regulated! You can only place a card in an empty column if it is exactly one rank lower than the Foundation Base Rank. (Look for the helpful ghost hints in empty slots!)
  • The Reserve: Clicking the Stock pile deals 7 cards across the 7 Reserve piles. No building is allowed on the reserves, but their top cards are always playable.

⚙️ Variants Available in Settings!

Change between the historical "Bernauer" and "Sorel" layout building rules. If the strict empty space rules are too hard, toggle the "Relaxed" mode to allow placing any card in an empty column!
